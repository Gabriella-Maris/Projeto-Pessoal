# Projeto-Pessoal

Meu projeto pessoal é Um localizador de escolas de futebol feminina de acordo com a cidade em que a pessoa mora. 

Pensei nesse projeto porque desde pequena eu sempre gostei muito de joagr futebol mas sempre foi extremamente dificil localizar
escolas de futebol feminina. 

Com base nisso, criarei um website para que a pessoa digite sua cidade (será somente destinado ao estado de São Paulo), e assim aparecam todas as escolas femininas mais conhecidas e registradas no google.
